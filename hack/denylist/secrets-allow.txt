# Suppresses secrets-heuristic.txt only, never secrets.txt. Python regex.
#
# Entries match the whole value rather than merely appearing on the line, so a
# real credential on a line that happens to say "example" is still caught.

# The value is an environment variable or a command substitution.
[:=]\s*["']?\$\{?[A-Za-z_][A-Za-z0-9_]*\}?["']?\s*$
[:=]\s*["']?\$\(

# The value is an obvious placeholder, in full.
[:=]\s*["']<[^>]*>["']
[:=]\s*["'](your|my|the)[-_ ][\w-]*["']
[:=]\s*["'](example|placeholder|redacted|changeme|secret|token|password|xxx+|\.\.\.)[\w-]*["']

# Credential shapes that must never be committed. Python regex.
#
# These are well-known public token formats, so listing them discloses nothing.
# Deployment-specific shapes go in secrets.local.txt, which is gitignored.
#
# High-confidence patterns only: a match here is almost certainly a real
# credential. The lower-confidence heuristic lives in secrets-heuristic.txt.
# This runs as a pre-commit hook, so a false positive blocks someone's work.
#
# Lengths are ranges rather than exact counts. Providers change token lengths,
# and an exact count silently stops matching when they do.

# --- cloud providers ---
\b(AKIA|ASIA|ABIA|ACCA)[0-9A-Z]{16}\b
\bAIza[0-9A-Za-z_\-]{30,45}\b
\bya29\.[0-9A-Za-z_\-]{20,}

# --- source forges ---
\bgh[pousr]_[A-Za-z0-9]{30,}\b
\bgithub_pat_[A-Za-z0-9]{20,}_[A-Za-z0-9]{50,}\b
\bglpat-[A-Za-z0-9_\-]{20,}\b

# --- model and SaaS providers ---
\bsk-ant-[A-Za-z0-9_\-]{24,}
\bxox[baprs]-[0-9A-Za-z\-]{10,}
\bsk_live_[0-9A-Za-z]{20,}
\bnpm_[A-Za-z0-9]{30,}\b
\bdop_v1_[a-f0-9]{60,}\b

# --- key material and bearer tokens ---
